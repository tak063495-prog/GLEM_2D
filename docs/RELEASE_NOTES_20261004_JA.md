# 2026-10-04 レビュー修正版（未公開・ドラフトPR）

基準: main `ce494de55a640f39dc250b45844acfeefd61c3f0`。Triela / Windows x64 / .NET SDK 8.0.425。
mainへの直接push、マージ、タグ作成、GitHub Release公開は行いません。

## 修正

- 円弧の底面角の符号を保持。対称静的円弧では駆動力が相殺し、有限FSを捏造せず診断。
  現行地表は水平のため、静的で対称な円弧探索の有効候補がゼロになる挙動変更があります。
- 底面長ΔLと水平幅bを区別。重量は層別面積×γ、載荷はqb、Bishopのc′b・ubは水平幅。
  境界を横切る線形底面では層ごとに厳密積分、円弧は条体ごとの弦で近似。
- Bishop反復の有限性と正のmαを確認、抵抗ゼロはFS=0の有限な収束解として扱います。
  未収束・非有限候補を探索から除外し、全無効時はGLEM-2004を表示。
- 即時沈下は既存式の根拠である均質な弾性半無限地盤に限定し、同物性層の分割による倍増を修正。
  異なるEs/ν・一部だけEsを指定するケースはGLEM-2005。全Es省略なら圧密のみ。
  有限厚多層弾性解と有限正層厚→0の極限は未実装（安全な暫定適用制限）。
- 二次圧縮開始を層別t95とし、解析期間と独立に既存圧密式を逆算。
- CoreのSearch/Settlement入口で有限性・物性・寸法・探索範囲等を検証しフィールド名付きエラー。
- autosave回帰は専用一時ファイルへ隔離し、実ユーザーの自動保存を削除しないようにしました。

## 独立根拠と参照値

層重量: 底面(0,1)→(2,3)は面積4m²、γ18で72kN/m。上層2mγ10/下層γ20なら45kN/m。
Bishop純粘着・α30°・l2m・W100・c10: F=20/50=0.4。
3条体Bishop: エンジンの固定点反復と独立した二分法でF=1.8291038995586373、残差約2.84e-14。
同物性の即時沈下は半無限地盤の閉形式で30.6360519377mm（q100,B=L6,Es20000,ν.3）、
10m1層と5m+5mで同一。詳細と出典: [METHODS.ja.md](METHODS.ja.md)。
旧参照の期待値変更は、幅/底面長の区別、独立二分法、純粘着の閉形式を根拠にしています。
旧有限FS試験は、静的対称形状を有限FSの参照として使わず、明示kh=.1または手入力の傾斜条体へ修正。

## 性能変更（修正コミット6952478とは分離）

Bishop内で層探索、水圧、重量、三角関数、c項/φ項を1回計算し、最後の条体帳票を1回だけ生成します。
演算順序・許容差・上限を維持。帳票は基準実装と同じ「最後に評価したFs」で生成し、戻りFsへ置換しません。
保持領域はCompute呼出し内に限定し、入力物性の変更後に古い値を再利用しません。
層別・水位/ru・符号付きα・部分載荷の固定seed150ケース、非収束・ゼロ抵抗・駆動ゼロを含め、
FS/Converged/Iterations/全SliceComputationと失敗コード・文言を厳密一致で比較しました。

Triela / Windows 10.0.26300 / .NET runtime 8.0.31、Release、1 worker、
DOTNET_TieredCompilation=0、tol=1e-10、maxIterations=200。100回warmup、9round交互順序、
各roundでGCを実施し中央値を採用。ピークRSSではなくGC.GetAllocatedBytesForCurrentThreadの呼出し当たり割当量。
初回値は別記録し、最初の3条体ケースにはJITを含みます。他サイズの初回値は同じメソッドが既にJIT済みです。
速度はBishop.Compute単体の計測であり、探索全体や全ユーザー入力の速度保証ではありません。

## 追加レビューの修正・再検証

- Bishop初期FS=1が負角のmα>0領域外にあるだけで、有効円弧を除外する問題を再現。
  領域外の反復値に限り、最大の極より右側で釣合い式をbracketし二分法へfallback。
  bracket拡大と二分法は残りのmax_iterationsを共有し、上限時はConverged=false。
  正のbracketが確認できない場合は未検証の根を採用しません。通常の固定点経路は維持。
- 独立3条体式 R(F)=600/(1-3/F²)+200-30F、F>sqrt(3)、[26,27]の二分法参照
  F=26.750864342576584。乾燥c100/φ45、cx0/cz−1/r6、γ18、17条体円弧は
  F=33.280056023023604。両者が収束し、実円弧が探索でも採用される回帰を追加。
- 旧コードを実行し、非有限Xの制御点から5条体を生成しJanbuがFS=NaN、Converged=trueを
  返す経路を再現。全3エンジンのCore入口で材料・載荷・条体の有限性を確認し、
  出口でもFSと全条体報告を確認。Janbuにもスケール付き駆動力ゼロ判定を追加。
- 制御点の非有限座標・重複X・地盤外深度・表現不能な分割数を拒否。実際の傾斜角を保持。
  直接Janbu UI経路も、不正入力から結果を公開しない回帰を追加。
- Release buildは警告0・エラー0、全128試験PASS・skip0、Core coverage 93.05%でgate PASS。
- 性能基準にも有限性とBishop領域修正を適用し、共有する正しさコードはcsprojでリンク。
  固定seed150例・符号付き円弧/3条体・1反復打切りを含め、全報告・収束・失敗状態が完全一致。
  上表・生データは再計測値へ更新しました。旧6.47〜7.75倍という測定値は新headの値ではありません。
